# Harvest Hub

A blockchain-powered supply chain transparency platform for agricultural produce. Track, verify, and ensure the quality, origin, and fair pricing of food from farm to consumer.

## Features
- Transparent supply chain tracking using blockchain
- Product verification and traceability
- Stakeholder dashboard for real-time updates
- Supply chain event tracking
- Modern UI with React, Vite, and shadcn/ui components

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Radix UI & shadcn/ui
- Blockchain integration (future scope)

## Getting Started

### Prerequisites
- Node.js (v18 or above)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Visit [http://localhost:8080](http://localhost:8080) to view the app.

### Build
```bash
npm run build
```

## Folder Structure
- `src/components/` – UI and feature components
- `src/pages/` – Application pages
- `src/lib/` – Utility functions
- `src/hooks/` – Custom React hooks
